PVE Storage Guard 用于保护 Proxmox VE 宿主机的管理面，避免批量导入、备份
或其他高吞吐任务造成共享磁盘 I/O 饥饿。

## 核心边界

- 以存储域/存储池为控制边界，而不是给每块虚拟磁盘建立互相竞争的控制器。
- 只控制显式登记的非关键磁盘；根盘和关键业务盘默认排除。
- PVE Adapter 负责平台语义，`storage-slo-guard` 只负责通用策略与分配。
- 默认 observer / shadow，只产生检测结果、限流建议与解释，不写入 PVE。
- 监控数据过期、有效状态未知、策略漂移或回读不一致时停止执行，绝不提速。

## 当前结论

历史回放比较了不限流、固定 20 MiB/s、阈值阶梯控制和有界 AIMD。当前候选
策略在三个反事实模型中没有比固定 20 更差的危险时长，并略微提高了模型中的
任务接纳量。但这只是单次事故上的模型估计，候选策略仍然只允许 shadow。

进入生产控制前必须完成：独立历史样本、1 Hz 延迟/PSI/队列/管理面探针、
非关键磁盘受控压测、故障注入、冷启动与回滚演练，以及明确的人工审批。

本项目是独立社区项目，与 Proxmox 官方没有隶属、赞助或背书关系。
