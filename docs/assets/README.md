# Documentation assets

Images in this directory must be generated from sanitized project data or the
local documentation site. Screenshots require the same pre-publication identity
and secret scan as text fixtures. Modeled charts must visibly say “modeled” or
“counterfactual”; observed screenshots must visibly say “observed”.

`policy-effect.svg` is generated by `poc/render_effect_chart.py` from the
reviewed `poc/results/report.json` golden file. CI uses `--check` to reject a
stale README/Pages copy.
