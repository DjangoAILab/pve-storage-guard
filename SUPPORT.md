# Support

PVE Storage Guard is an early community project, not an official Proxmox
product and not a substitute for tested backups or vendor support.

- Use GitHub issues for reproducible bugs and narrowly scoped feature requests.
- Use discussions for design questions and operational patterns once enabled.
- Use private vulnerability reporting for security or conduct reports.

Always sanitize diagnostic material according to
[the case-study contract](docs/CASE-STUDY.md#sanitization-contract). Do not post
credentials, private network details, raw production logs, host/guest identity,
or customer data.
